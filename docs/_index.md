> **Разделяй и властвуй** - принцип, по которому проектируется MVP. Все, что не влияет на основной пользовательский сценарий, убираем из первой версии.

Сервис проектируется как простой финансовый трекер аренды для частных собственников и небольшого арендного бизнеса в России.

Главная задача MVP - дать собственнику одно место, где он видит объекты, аренды, необязательные контакты арендаторов, доходы, расходы, регулярные операции, важные даты и прогноз прибыли по объектам.

## Основной пользователь

Собственник - пользователь сервиса, который сдает в аренду квартиру, комнату, дом, гараж, бокс, машиноместо, коммерческое помещение, кабинет, складскую ячейку, место хранения или несколько таких объектов.

Арендатор - не пользователь сервиса в MVP. Это необязательный контакт внутри кабинета собственника.

## MVP-рамки

Входит в MVP:

* адаптивный веб-сервис;
* вход по российскому номеру телефона с одноразовым кодом на почту;
* учет объектов, аренд и необязательных контактов арендаторов;
* операции доходов и расходов на прошлую, текущую или будущую дату;
* регулярные операции;
* напоминания собственнику на почту (и Web Push);
* базовый P&L и прогноз по операциям;
* тарифы по количеству активных объектов;
* платная онлайн-подписка через T-Кассу;
* минимальная админка для поддержки подписок.
