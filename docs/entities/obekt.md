Объект - минимальная сдаваемая единица, по которой можно создать аренду и вести денежные записи.

Примеры объектов: квартира, комната, дом, коммерческое помещение, офисный кабинет, складская ячейка, гараж, бокс, машиноместо, участок.

## Поля

Обязательные поля:

* Тип
* Адрес

Необязательные поля:

* название — если не указано, генерируется из типа: «Моя квартира 1», «Мой гараж 1», «Моё коммерческое помещение 1»; серийник — число объектов этого типа у владельца (включая архивные, без удалённых) плюс один (карта #984, тикет #1001)
* описание
* фотографии
* характеристики

## Типы объекта

* Квартира

## Фотографии

В MVP у объекта может быть до 10 фотографий. Первое фото используется как обложка в списке объектов.

## Характеристики объекта

Характеристики объекта (Property Attributes) — пер-типовые типизированные характеристики: число комнат, площади, этаж, год постройки, материал стен и т.п. Все характеристики необязательные. Набор доступных характеристик определяется типом объекта (один из 11 типов). Ключи и значения хранятся на английском в `snake_case`; русские подписи показываются на фронте и в админке.

### Модель хранения

Характеристики хранятся в JSONB-колонке `attributes` таблицы `properties`. Записываются только заполненные ключи; значения `null` не пишутся. «Нет характеристик» — это пустой объект `{}`. Валидация ключей, типов и диапазонов значений живёт в каталоге приложения, а не в схеме БД: CHECK-констрейнтов на ключи в БД нет. Каталог характеристик — источник истины для конкретного набора полей по типу объекта.

### Каталог по типам

У каждого из 11 типов свой набор полей:

* **Квартира** и **Апартаменты** — комнаты, общая/жилая/кухонная площадь, этажи, санузел, балкон, ремонт, год постройки, высота потолков, парковка. Апартаменты используют набор квартиры.
* **Студия** — набор квартиры (кросс-правила те же: этаж ≤ этажности, жилые/кухонная ≤ общей), карта #984 тикет #1003.
* **Комната** — комнаты, площадь, этажи, санузел, балкон, ремонт, год постройки.
* **Дом** — участок (площадь и категория), площадь дома, этажность, комнаты, тип дома, материал, санузел, душ, год постройки.
* **Офис** и **Коммерческое помещение** — тип здания, этажи, площадь, комнаты, вход, ремонт. Коммерческое помещение использует набор офиса.
* **Склад** — площадь, вход, тип здания.
* **Гараж** — площадь, материал.
* **Машиноместо** — площадь, расположение, уровень, номер места.
* **Участок** — площадь и категория участка.

### Единицы измерения

Единицы зафиксированы для характеристик и показываются при вводе и в карточке: площади — в м², площадь участка — в сотках, высота потолков — в метрах.

### Семантика записи

При создании и редактировании характеристики передаются целиком как полная замена (идемпотентно). Если поле характеристик отсутствует в запросе на обновление — характеристики не трогаются. Пустой объект `{}` означает «очистить все характеристики».

### Смена типа объекта

При смене типа уже сохранённые характеристики не удаляются (lossless): они остаются в хранилище без изменений. Смысл хранимых ключей при чтении, показе и будущей публикации определяет каталог ТЕКУЩЕГО типа. «Чужие» ключи прежнего типа инертны — они остаются в хранилище, но не показываются и не валидируются, пока не будут перезаписаны следующим сохранением. Смена типа проходит тихо, без уведомлений (решение владельца 2026-09-01: прежний нотис «сохранятся, но будут скрыты» убран из интерфейсов).

## Статусы объекта

Статус занятости вычисляется автоматически:

* Свободен
* Сдан

Служебные статусы ставятся вручную:

* На ремонте
* Архив

## Правила статусов

* Если у объекта есть открытая аренда, объект считается `Сдан`.
* Если открытой аренды нет и нет ручного служебного статуса, объект считается `Свободен`.
* Аренда в статусе `Требует действия` продолжает занимать объект.
* Статус `На ремонте` можно поставить только свободному объекту.
* Если объект в статусе `На ремонте` или `Архив`, на него нельзя создать новую аренду.
* По объекту в статусе `На ремонте` можно создавать операции и регулярные операции.
* Ручной перевод объекта в `Архив` запрещен, если по объекту есть открытая аренда.
* При переводе объекта в `Архив` объект скрывается из активных списков и освобождает место в тарифном лимите.
* История архивного объекта остается в отчетах за прошлые периоды.
* По архивному объекту нельзя создавать, редактировать или удалять аренды, операции, регулярные операции и настройки напоминаний.
* При архивировании будущие неотредактированные операции удаляются, а регулярные операции приостанавливаются.
* Архивный объект можно вернуть из архива, если тарифный лимит позволяет.
* При возврате из архива регулярные операции возобновляются с текущей даты; пропущенные операции за период архива не создаются.
* Тарифный автоархив является исключением: он может архивировать объект с открытой арендой и принудительно завершает такую аренду (статус `Завершена`, регулярные операции приостанавливаются, будущие неотредактированные операции удаляются, напоминания отменяются). Возврат объекта из архива не восстанавливает завершенную аренду.

## Удаление объекта

Объект можно удалить безвозвратно в одном из двух режимов.

* Каскадное удаление (`cascade`) удаляет объект вместе со всеми его арендами, операциями, регулярными операциями и напоминаниями.
* Удаление с отвязкой (`detach`) удаляет только объект. Его аренды, операции, регулярные операции и напоминания сохраняются без привязки к объекту (`property_id = null`).
* При `detach` регулярные операции объекта приостанавливаются, будущие неотредактированные операции удаляются, а напоминания отменяются — как при архивировании.
* Фотографии объекта удаляются в обоих режимах: без объекта они не имеют смысла.
* Объект с открытой арендой удалить нельзя ни в одном из режимов: сначала собственник завершает аренду.
* Состояние «без объекта» — легальное: отвязанные аренды, операции и регулярные операции продолжают существовать и видны в истории.
* В финансовом отчете отвязанные операции попадают в отдельную группу «Без объекта».
* Удаление безвозвратно в обоих режимах, восстановление объекта не предусмотрено.

## Лимит тарифа

Тарифный лимит считает только неархивные объекты.
