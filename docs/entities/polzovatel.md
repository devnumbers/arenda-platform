Пользователь — аккаунт, который входит в сервис по номеру телефона и коду, отправляемому на привязанный email.

## Роли

В MVP есть две роли:

* Собственник - основной пользователь, который ведет объекты, аренды, необязательные контакты арендаторов, операции, регулярные операции, настройки напоминаний и подписку.
* Админ - внутренний пользователь сервиса для поддержки подписок и доступа. Админ не ведет данные собственников, но может вести собственный тестовый кабинет для проверки тарифной логики.

Арендатор не является пользователем сервиса в MVP.

## Поля собственника

Обязательные поля:

* номер телефона;
* email;
* роль.

Email обязателен для входа и подтверждается при первом успешном вводе кода.

Необязательные поля:

* имя;
* фамилия;
* отчество;

## Ограничения

* Номер телефона используется как логин.
* Регистрация и вход объединены: если пользователь подтвердил номер телефона и email кодом, и такого пользователя еще нет, система создает аккаунт собственника.
* Общий flow входа — «телефон → код». Для уже зарегистрированного телефона код отправляется на сохранённый email сразу после ввода номера; шаг ввода email показывается только новым пользователям (см. ADR 0015).
* По умолчанию новый пользователь получает роль `Собственник`.
* Роль `Админ` назначается внутренне и не доступна через самостоятельную регистрацию.
