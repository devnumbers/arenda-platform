Пользователь - аккаунт, который входит в сервис по телефону и SMS-коду.

## Роли

В MVP есть две роли:

* Собственник - основной пользователь, который ведет объекты, аренды, необязательные контакты арендаторов, операции, регулярные операции, SMS-настройки и подписку.
* Админ - внутренний пользователь сервиса для поддержки подписок и доступа. Админ не ведет данные собственников, но может вести собственный тестовый кабинет для проверки тарифной логики.

Арендатор не является пользователем сервиса в MVP.

## Поля собственника

Обязательные поля:

* номер телефона;
* роль.

Необязательные поля:

* имя;
* фамилия;
* отчество;
* email;

## Ограничения

* Номер телефона используется как логин.
* Регистрация и вход объединены: если пользователь подтвердил номер телефона SMS-кодом и такого пользователя еще нет, система создает аккаунт собственника.
* По умолчанию новый пользователь получает роль `Собственник`.
* Роль `Админ` назначается внутренне и не доступна через самостоятельную регистрацию.
