Тариф определяет лимит активных объектов и стоимость подписки.


## Тарифы

| Тариф | Лимит активных объектов | Месяц | Год |
| --- | ---: | ---: | ---: |
| Базовый | 1 | 0 ₽ | 0 ₽ |
| Про | 5 | 490 ₽ | 4400 ₽ |
| Бизнес | Без ограничения | 990 ₽ | 8900 ₽ |

## Активные объекты

В лимит тарифа входят все неархивные объекты. Архивные объекты не занимают лимит, но сохраняют историю.

## Подписка пользователя

Подписка пользователя хранит текущий тариф, лимит активных объектов и источник оплаты.

Есть два источника подписки:

* Платная подписка - для собственника. Платные тарифы оплачиваются через T-Кассу, подписка продлевается автоматически.
* Служебная подписка - для админского аккаунта. Админ может назначить себе любой тариф для проверки тарифной логики, но деньги не списываются.

Для платной подписки:

* повышение тарифа применяется сразу после оплаты;
* понижение тарифа применяется в конце оплаченного периода;
* отмена подписки отключает автопродление, но тариф работает до конца оплаченного периода.

Для служебной подписки:

* тариф действует без срока, пока админ сам его не сменит;
* T-Касса, автосписания, льготный период и платежные требования не применяются;
* смена тарифа применяется сразу и полностью, включая лимиты, автоархив при понижении и восстановление после повышения.

## Неуспешное списание

Этот раздел применяется только к платной подписке собственника.

Если автосписание не прошло:

* начинается льготный период 7 дней;
* в течение льготного периода пользователь сохраняет текущий тариф;
* если оплата не прошла за 7 дней, тариф понижается;
* если объектов больше нового лимита, лишние объекты автоматически архивируются.

## Автоархив при понижении

Система оставляет активными объекты в таком порядке:

* сначала объекты с открытой арендой;
* затем самые недавно обновленные объекты.

Если открытых аренд больше лимита, лишние объекты с открытыми арендами тоже архивируются. Это системное исключение из правила ручного архива.

При тарифном автоархиве:

* объект переводится в `Архив`;
* открытая аренда переводится в системный статус `Архив`;
* будущие неотредактированные операции по объекту удаляются;
* регулярные операции приостанавливаются и не создают новые операции, пока объект в архиве;
* будущие напоминания по объекту останавливаются;
* история сохраняется.

После оплаты или повышения тарифа объект можно вернуть из архива, если лимит позволяет. При возврате регулярные операции возобновляются с текущей даты без создания операций за период архива.
