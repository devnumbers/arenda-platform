# ADR 0050: shadcn/ui — база дизайн-слоя фронтенда

## Status

Accepted

## Context

Контекст «Платежи» выходит на фронтенд: по тикету #449 (карта #443) строится дизайн-слой переиспользуемых компонентов из Figma и первые экраны. До этого момента база была гибридной: самописные CSS-модули в `shared/ui` поверх токенов `shared/styles/tokens.css` плюс HeroUI v3 (beta) в 22 файлах виджетов (модалки, drawer, лоадеры); правила требовали верифицировать HeroUI через `heroui-react` MCP.

HeroUI v3 остаётся beta, не покрыт обучающими данными агентов, а его стилевая модель (tailwind-variants, собственная oklch-тема) расходится с дизайн-системой Figma (шрифт Onest, акцент #2B7FFF, кастомные состояния). При этом Tailwind v4 уже подключён в приложении (`app/globals.css: @import "tailwindcss"`, плагин `@tailwindcss/postcss`) — движок утилит доступен без смены стека. Владелец продукта выбрал shadcn/ui (grilling-сессия #449, раунд 3, 2026-08-25).

## Decision

- База нового UI — **shadcn/ui** (`https://ui.shadcn.com/docs/components`): компоненты генерируются в репозиторий (CLI) поверх нестилизованных Radix-примитивов (Dialog, Popover, Checkbox, RadioGroup, Switch и др.) и стилизуются Tailwind-утилитами поверх наших токенов. Дизайн-слой платежей и все новые экраны верстаются на shadcn + Tailwind.
- Каноничные дизайн-токены остаются в `shared/styles/tokens.css` (палитра совпадает с Figma) и пробрасываются в Tailwind через `@theme`. Шрифт новых экранов — Onest (`next/font`); Manrope остаётся на старых экранах до отдельной миграции.
- HeroUI v3 не используется в новом коде. Существующие HeroUI-виджеты продолжают работать до отдельной миграции, после которой зависимость `@heroui/*` удаляется. Правила `AGENTS.md`, `apps/frontend/AGENTS.md`, `apps/frontend/CODING_STANDARDS.md` и скилла `frontend` ревизованы соответственно.
- Существующие CSS-модульные компоненты `shared/ui` не переписываются: старые экраны продолжают их использовать; переходческое дублирование (свой Button/TextField и shadcn-версии) — осознанная цена постепенной миграции.

## Consequences

- Свой код, свой контроль: shadcn-компоненты живут в репо, обновляются осознанно; стабильные Radix-примитивы дают доступность из коробки.
- На время миграции в приложении сосуществуют три источника стилей (CSS-модули, Tailwind-утилиты, легаси HeroUI) — это принятый переходный период, а не целевое состояние.
- Миграция легаси-виджетов с HeroUI и удаление зависимости — отдельное последующее усилие (за пределами среза платежей, см. карту #443, Out of scope).
- `heroui-react` MCP остаётся в конфигурации только как документация легаси-слоя; для нового кода источник — доки shadcn/ui и Radix.
