Аренда создается для одного объекта. Контакт арендатора можно указать сразу или оставить пустым.

## Обязательные поля

* Объект
* Дата начала
* Месячная арендная ставка
* День оплаты

## Необязательные поля

* Арендатор
* Дата окончания
* Залог как справочная сумма
* Комментарий
* напоминание по арендной плате

## Правила

* Черновиков аренды нет. Если обязательные поля не заполнены, аренда не создается.
* Аренду можно создать без контакта арендатора.
* Если контакт арендатора не указан, в интерфейсе показывается `Арендатор не указан`.
* Объект считается `Сдан`, если у него есть открытая аренда, даже если контакт арендатора не указан.
* Нельзя создать больше одной открытой аренды для одного объекта.
* Аренда работает только с месячной ставкой.
* Первый и последний месяц создаются полной суммой, без пропорционального расчета.
* Если указан залог, это только справочное условие аренды.

## Арендные операции

Создание аренды создает системную регулярную доходную операцию категории `Арендная плата`.

Первая операция создается на дату начала аренды. Следующие операции создаются по выбранному дню оплаты.

Если выбранного дня нет в месяце, используется последний день месяца.

Если дата окончания указана, арендные операции создаются только на даты не позже даты окончания.

Если дата окончания не указана, система создает операции на 100 лет вперед.

## Аренда в будущем

Если дата начала аренды в будущем, аренда создается в статусе `Ожидает начала`, а будущие арендные операции создаются как прогноз.

Когда наступит дата начала, аренда становится активной.

## Аренда задним числом

Если дата начала аренды в прошлом, система создает арендные операции за прошлые периоды как уже внесенную историю.

Пользователь не выбирает режим `оплачено` или `долг`: в MVP нет отдельного учета задолженности.

## Дата окончания

Дата окончания необязательна.

Дата окончания включительная. Если дата окончания указана, операции создаются только на даты не позже даты окончания. В саму дату окончания аренда еще считается активной.

На следующий день после даты окончания новые операции не создаются, а аренда переходит в состояние `Требует действия`.

## Дополнительные операции объекта

Создание аренды создает только арендную регулярную операцию.

Другие доходы и расходы по объекту собственник создает как операции или регулярные операции.
