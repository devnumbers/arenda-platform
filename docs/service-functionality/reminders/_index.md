title: Напоминание
order: 1
---

В MVP напоминания отправляются на почту (и Web Push) только собственнику.

Собственник может отключать типы напоминаний на странице «Уведомления» в профиле. Напоминание, пропущенное из-за запрета, получает терминальный статус `skipped`.

При первом входе в кабинет собственник один раз видит онбординг-попап о напоминаниях с выбором типов; дальнейшая настройка — на странице «Уведомления» в профиле.
