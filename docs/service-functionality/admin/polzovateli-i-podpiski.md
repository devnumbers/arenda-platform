Админ видит пользователей и состояние их подписок.

## Данные на странице

* пользователь;
* номер телефона;
* роль;
* текущий тариф;
* срок действия тарифа;
* платежный статус;
* количество активных объектов;
* количество архивных объектов.

## Действия

Админ может:

* вручную назначить тариф;
* продлить срок действия тарифа;
* заблокировать тариф;
* снять блокировку тарифа.

Для собственного админского аккаунта админ может назначить любой тариф как служебную подписку. Служебная подписка нужна для проверки тарифной логики, действует без срока и не участвует в списаниях, автопродлении, льготном периоде и платежных требованиях.

Служебную подписку нельзя назначить собственнику. Для собственников ручное назначение и продление тарифа остаются поддерживающими действиями в рамках платной подписки.

У служебной подписки нет платежного статуса, требующего действия: она не ожидает оплаты и не уходит в просрочку.

Смена служебного тарифа применяется сразу и полностью: новый лимит действует немедленно, при понижении применяются обычные правила тарифного автоархива, при повышении объект можно вернуть из архива, если лимит позволяет.

## Ограничения

* Админ не редактирует объекты и финансы собственника.
* Админ не создает аренды, операции и регулярные операции за собственника.
* Админ может вести собственный тестовый кабинет с объектами, арендами и финансами для проверки тарифной логики.
* Возвраты и ручные платежные корректировки не входят в MVP.
