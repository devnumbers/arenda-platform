Тарифы ограничивают количество активных объектов.

## Тарифы MVP

| Тариф | Активные объекты | Месяц | Год |
| --- | ---: | ---: | ---: |
| Базовый | 1 | 0 ₽ | 0 ₽ |
| Про | 5 | 490 ₽ | 4400 ₽ |
| Бизнес | Без ограничения | 990 ₽ | 8900 ₽ |

## Что считается объектом

В лимит входят все неархивные объекты.

Архивные объекты:

* не занимают лимит;
* скрыты из активных списков;
* доступны только для просмотра истории;
* сохраняют историю в отчетах за прошлые периоды.

Объект можно вернуть из архива, если тарифный лимит позволяет.

## Источник подписки

Платная подписка собственника использует цены тарифов и оплачивается через T-Кассу.

Служебная подписка админа нужна только для проверки тарифной логики. Админ может назначить себе любой тариф, но списания, автопродление, льготный период и дата окончания для такой подписки не применяются. Это не меняет цену тарифа для собственников.

## SMS

SMS-напоминания включены в тарифы без отдельного лимита. Контроль стоимости достигается ограниченным набором событий.

Если админ заблокировал тариф пользователя, новые SMS не отправляются. После снятия блокировки ретроспективные SMS не догоняются.

## Не учитывается в MVP

Маркетинговые features тарифов не являются функциональной спецификацией MVP. В первой версии фиксируются только цена и лимит активных объектов.
