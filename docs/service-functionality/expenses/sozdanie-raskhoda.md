Расход - операция с направлением `Расход`.

## Обязательные поля

* объект;
* сумма;
* дата операции;
* категория.

## Необязательные поля

* комментарий;
* SMS-напоминание.

## Категории

* ЖКХ
* Ремонт
* Налог
* Прочее

## Правила

* Расход всегда привязан к объекту.
* Расход попадает в отчет по дате операции.
* Дата создания расхода не влияет на P&L.
* Расход можно создать прошлой, текущей или будущей датой.
* Будущий расход считается прогнозом выбранного периода.
* Повторяющийся расход создается через регулярную операцию.
* Ремонт учитывается как расход без отдельного workflow задач.
* Налоги учитываются как расходы вручную, без автоматического расчета.
* Расход категории `ЖКХ` можно создать по объекту независимо от наличия аренды.
* Расход нельзя создать по архивному объекту.
* Сервис не рассчитывает ЖКХ по счетчикам, тарифам, площади или нормативам.
