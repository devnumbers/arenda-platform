title: P&L и отчеты

---

Аналитика MVP показывает доходы, расходы, чистую прибыль и прогноз по операциям.

## Принцип расчета

P&L считается по операциям выбранного периода:

* доходы - операции с направлением `Доход`;
* расходы - операции с направлением `Расход`;
* чистая прибыль = доходы - расходы.

Дата создания записи не влияет на P&L. Операции попадают в отчет по дате операции.

Если пользователь создал или исправил операцию прошлой датой, P&L соответствующего прошлого периода пересчитывается сразу.

Если выбранный период включает будущие даты, будущая часть отчета является прогнозом.

## Периоды

По умолчанию показывается текущий месяц.

Пользователь может выбрать произвольный период.

## Показатели

В MVP показываются:

* доходы за период;
* расходы за период;
* чистая прибыль за период;
* прогноз доходов, расходов и прибыли, если период включает будущие даты;
* разбивка доходов, расходов и прибыли по объектам;
* структура доходов по фиксированным категориям;
* структура расходов по фиксированным категориям.

## Ограничения

* Экспорт отчетов не входит в MVP.
* Налоговый расчет не входит в MVP.
* Отчет по occupancy rate и дням простоя не входит в MVP.
* Начисленный метод учета не входит в MVP.
* Расчет ЖКХ по счетчикам, тарифам, площади или нормативам не входит в MVP.
* Автоматическое сопоставление доходов и расходов не входит в MVP.
