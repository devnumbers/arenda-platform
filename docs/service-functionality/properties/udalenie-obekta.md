---
title: Удаление объекта
order: 1
---

Объект можно удалить безвозвратно. Удаление выполняется в одном из двух режимов, которые пользователь выбирает в диалоге удаления.

## Режимы удаления

* **Каскадное удаление (`cascade`)** — удаляет объект вместе со всеми его данными: арендами, операциями, регулярными операциями и напоминаниями. Подходит, когда история по объекту больше не нужна.
* **Удаление с отвязкой (`detach`)** — удаляет только объект. Аренды, операции, регулярные операции и напоминания сохраняются, но теряют привязку к объекту (`property_id = null`). При этом регулярные операции приостанавливаются, будущие неотредактированные операции удаляются, а напоминания отменяются — как при архивировании.

Фотографии объекта удаляются в обоих режимах.

## Ограничения

* Объект с открытой арендой удалить нельзя ни в одном из режимов. Сначала собственник завершает аренду, затем удаляет объект.
* Удаление безвозвратно: восстановить объект и каскадно удаленные данные нельзя.

## Данные без объекта

Отвязанные при `detach` аренды, операции и регулярные операции продолжают существовать как записи «без объекта»:

* в API и интерфейсе у них `property_id` равен `null`;
* в финансовом отчете они попадают в отдельную группу «Без объекта»;
* приостановленные регулярные операции новых операций не создают.
