---
title: Создание объекта
order: 1
---

Пользователь создает объект как минимальную сдаваемую единицу.

## Обязательные поля

* Название
* Тип
* Адрес

## Необязательные поля

* Описание
* Фото объекта
* Комментарий

## Правила

* Адрес выбирается через DaData.
* Один адрес может использоваться у нескольких объектов.
* Количество активных объектов ограничено тарифом.
* Архивные объекты не занимают тарифный лимит.
* В MVP у объекта может быть до 10 фотографий.
* При создании объекта аренды, операции и регулярные операции не создаются автоматически.

## После создания

После сохранения объекта сервис предлагает:

* создать аренду для объекта;
* создать операцию;
* создать регулярную операцию;
* оставить объект свободным.

Если пользователь оставляет объект свободным, объект появляется в списке со статусом `Свободен`.

Создать аренду можно только по объекту без открытой аренды и без статуса `На ремонте` или `Архив`.
