Можно редактировать название, тип, адрес, описание, фото и комментарий объекта.

## Статусы

Пользователь может вручную поставить служебный статус:

* На ремонте
* Архив

Статусы `Свободен` и `Сдан` вычисляются системой.

## Ограничения

* На объект в статусе `На ремонте` или `Архив` нельзя создать новую аренду.
* Статус `На ремонте` можно поставить только свободному объекту.
* По объекту на ремонте можно создавать операции и регулярные операции.
* Ручной архив объекта с открытой арендой запрещен. Сначала собственник завершает аренду, затем архивирует объект.
* Архивный объект скрывается из активных списков и освобождает тарифный лимит.
* Архивный объект доступен только для просмотра истории. Новые аренды, операции, регулярные операции и напоминания по нему не создаются.
* По архивному объекту нельзя редактировать или удалять финансовые записи.
* При архивировании будущие неотредактированные операции удаляются, регулярные операции приостанавливаются.
* Объект можно вернуть из архива, если тарифный лимит позволяет.
* При возврате регулярные операции возобновляются с текущей даты без создания операций за период архива.
* История архивного объекта остается в отчетах за прошлые периоды.

Тарифный автоархив является системным исключением: он может архивировать объект с открытой арендой и переводит такую аренду в статус `Архив`.
