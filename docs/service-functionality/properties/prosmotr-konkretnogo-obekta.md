title: Просмотр конкретного объекта
order: 1
---

Карточка объекта показывает всю информацию по конкретной сдаваемой единице.

## Данные на странице

* название, тип, адрес и описание;
* фотографии;
* текущий статус;
* открытая аренда, если есть;
* арендатор открытой аренды или `Арендатор не указан`, если объект сдан без контакта арендатора;
* операции доходов и расходов по объекту;
* регулярные операции по объекту;
* история завершенных аренд;
* P&L и прогноз за выбранный период.

## Действия

Пользователь может:

* перейти к редактированию объекта;
* создать аренду, если объект свободен и доступен;
* завершить открытую аренду;
* создать операцию;
* создать регулярную операцию;
* архивировать объект, если по нему нет открытой аренды;
* вернуть объект из архива, если тарифный лимит позволяет.

Если объект в архиве, финансовые записи доступны только для просмотра. Создание, редактирование и удаление финансовых записей по архивному объекту недоступны.
