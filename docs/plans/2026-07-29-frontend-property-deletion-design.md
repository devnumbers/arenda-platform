# Удаление объекта на странице объекта (frontend)

## Контекст
В бекенде реализован endpoint `DELETE /properties/{id}?mode=cascade|detach`. Нужно добавить UI для этого на странице объекта.

## Целевое поведение
- В верхнем меню страницы объекта (`PropertyActionMenu`) добавить пункт «Удалить объект».
- При нажатии открывается `PropertyDeleteModal`.
- Если у объекта нет открытой аренды, модал предлагает выбор:
  - «Удалить всё» → `mode=cascade`.
  - «Удалить только объект» → `mode=detach`.
  - «Отмена» → закрыть модал.
- Если у объекта есть открытая аренда (`currentLease`), модал не показывает выбор режима, а показывает:
  - заголовок «Нельзя удалить объект»;
  - текст «Объект нельзя удалить, пока есть незавершённая аренда»;
  - краткую информацию об аренде (арендатор, даты);
  - кнопку «Завершить аренду» — закрывает модал удаления и открывает существующий `PropertyEndLeaseModal`;
  - кнопку «Отмена».
- После успешного удаления — редирект на `ROUTES.properties` и тост «Объект удалён».
- При ошибке — тост «Не удалось удалить объект» с деталем от бекенда.

## Подход
Один адаптивный модал (`PropertyDeleteModal`), который внутри переключается между двумя состояниями в зависимости от наличия `currentLease`. Это минимизирует количество компонентов и состояния.

## UI-компоненты
- `PropertyActionMenu` — добавить пункт `delete`.
- `PropertyDeleteModal` — новый компонент на базе HeroUI `Modal`.
- `PropertyDetailPage` — управление состоянием модала, вызов мутации, обработка редиректа.

## API
- Новый хук `useDeleteProperty(mode)` в `features/properties/api/hooks.ts`.
- URL: `DELETE /properties/${id}?mode=${mode}`.
- `onSuccess`: инвалидировать `propertyKeys.list`, `propertyKeys.detail(id)` и связанные lease/operation keys.
- `onError`: fallback через `notify.scenarios.property.deleteError`.
- Необходимо перегенерировать `shared/api/generated.ts`.

## Уведомления
- Добавить `property.deleted` → «Объект удалён».
- Добавить `property.deleteError` → «Не удалось удалить объект».

## Сценарии ручной проверки
1. Объект без аренды → выбираем «Удалить всё» → объект исчезает из списка.
2. Объект без аренды → выбираем «Удалить только объект» → объект исчезает, аренды/операции остаются с `property_id = NULL`.
3. Объект с открытой арендой → модал показывает блок аренды → «Завершить аренду» → аренда завершается → повторное открытие модала показывает выбор режима.
4. Отмена в любом состоянии закрывает модал без запроса.
