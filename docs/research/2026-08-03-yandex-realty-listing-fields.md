# Поля мастера создания объявления Яндекс Недвижимости (аренда)

- **Дата сбора:** 2026-08-03
- **Источник:** https://realty.yandex.ru/management-new/add/ (мастер подачи объявления, без авторизации)
- **Тикет:** https://github.com/devnumbers/arenda-platform/issues/122
- **Метод:** ручной обход мастера через Playwright MCP, фиксация accessibility-снапшотов. Снапшоты сохранены в `.playwright-mcp/`:
  - `page-2026-08-03T13-02-26-627Z.yml` — Квартира (снят ранее)
  - `komnata-form.yml` — Комната
  - `dom-form.yml` — Дом / дача
  - `garage-form.yml` — Гараж
  - `commercial-form.yml` — Коммерческая (без выбранного назначения)
  - `commercial-office-form.yml` — Коммерческая / Для офиса
  - `commercial-retail-form.yml` — Коммерческая / Торговое помещение
  - `commercial-food-form.yml` — Коммерческая / Общепит
  - `commercial-warehouse-form.yml` — Коммерческая / Склад
  - `commercial-land-form.yml` — Коммерческая / Земля комм. назначения

## Как устроен мастер

- Тип объявления: **Продать / Сдать длительно / Сдать посуточно**. Для Гаража и Коммерческой варианта «Сдать посуточно» **нет**.
- Тип недвижимости при «Сдать длительно»: **Квартира, Комната, Дом / дача, Гараж, Коммерческая** — 5 типов. Типа «Участок» в аренде **нет** (он появляется только при «Продать»).
- На момент сбора мастер открывался сразу как одностраничная форма: выбор типа объявления и типа недвижимости переключает набор секций формы на той же странице (воронка «Яндекс Аренды» с шагом «Хочу сдать сам» в этой сессии не появлялась — вероятно, из-за сохранённого состояния предыдущего прохода).
- Адрес: отдельная секция с кнопкой выбора города (по умолчанию «Москва») и текстовым полем с подсказками. У квартиры и комнаты плейсхолдер «Укажите адрес или название ЖК», у остальных — «Укажите адрес».
- Без авторизации форма заполняется целиком; публикация и блок «Контакты» требуют регистрации («Зарегистрируйтесь, чтобы добавить контакты и опубликовать объявление. Заполненные данные — сохранятся»).
- Справа отображается процент заполнения объявления (наблюдалось 45–72 % в зависимости от типа).
- Пометок обязательности (звёздочек) в accessibility-дереве не видно; при незаполненном/наследованном адресе появляется сообщение «Некорректное значение поля». Точный список обязательных полей из снапшотов не извлекается — см. «Пробелы».

Обозначения типов ввода ниже: `текст` — текстовое поле, `число` — числовое поле, `radio` — выбор одного значения, `checkbox` — множественный выбор, `select` — выпадающий список, `file` — загрузка файла.

## Квартира

### Адрес
- Город — кнопка-переключатель (по умолчанию «Москва»).
- Адрес или название ЖК — `текст` с автоподсказками.

### О доме
- Год постройки — `число`.
- Высота потолков, м — `число`.
- Тип парковки — `radio`: Закрытая, Подземная, Открытая.

### О квартире
- Комнат — `radio`: 1, 2, 3, 4, 5, 6, 7+, Студия.
- Площадь, м² — три `числа`: Общая, Жилая, Кухня.
- Этаж — два `числа`: «этаж» из «всего этажей».
- Санузел — `radio`: Совмещённый, Раздельный, Более одного.
- Балкон — `radio`: Балкон, Лоджия; кнопка **«+ Добавить»** (можно указать несколько).
- Ремонт — `radio`: Косметический, Евро, Дизайнерский, Требуется.
- Окна — `checkbox`: Во двор, На улицу.

### Планировка (только у квартиры)
- Загрузка изображения планировки — `file`.

### Фотографии
- Загрузка фото — `file`, максимум 30 фото до 10 Мбайт. Подсказка: «Сфотографируйте все комнаты, кухню, санузел, коридор, балкон, вид из окна, фасад здания, подъезд».
- Умные фотографии — `checkbox` «Включить умную сортировку» (включён по умолчанию).

### Видео
- Ссылка на YouTube — `текст`.

### Удобства и подробности
- Описание — `текст` (многострочный, «Опишите недвижимость»).
- Чекбоксы (14): Интернет, Стиральная машина, Холодильник, Посудомойка, Мебель на кухне, Кондиционер, Можно с животными, Можно с детьми, Мебель в квартире, Лифт, Мусоропровод, Консьерж, Телевизор, Закрытая территория.

### Цена и условия сделки
- Цена — `число`, ₽ / месяц.
- Торг — `radio`: Возможен, Нет.
- Залог — `число` (Сумма, ₽) + `radio`: Без залога, 50%, 100%.
- Комиссия агента — `число` (Процент, %) + `radio`: Без комиссии, 50%, 100%.
- Минимальный срок аренды, мес. — `checkbox` «Есть» (при включении, судя по подписи, задаётся количество месяцев).
- Коммунальные платежи — `radio`: Включены в стоимость, Только счётчики (по умолчанию), Вся квитанция.
- Онлайн-показ — `checkbox` «Готовы показать онлайн».

### Контакты
- Требуют регистрации (без авторизации полей контактов нет).

## Комната

Совпадает с квартирой, кроме следующего.

### О квартире (заголовок секции остаётся «О квартире»)
- Комнат — `radio`: 2, 3, 4, 5, 6, 7+ (**без «1» и «Студия»** — сдаётся комната, минимум 2 комнаты в квартире).
- Комнат в сделке — `radio`: 1, 2, 3, 4, 5, 6 (неактивны до выбора «Комнат»; сколько комнат сдаётся).
- Площадь, м² — два `числа`: Общая, Кухня (**без «Жилая»**).
- Покрытие пола — `radio`: Линолеум, Ламинат, Паркет, Кафель (**уникальное поле комнаты, у квартиры его нет**).
- Этаж, Санузел, Балкон (с «+ Добавить»), Ремонт, Окна — как у квартиры.

### Прочее
- Секции «Планировка» **нет**.
- Подсказка к фото адаптирована: «Сфотографируйте комнату, кухню, санузел…».
- Удобства — тот же набор из 14 чекбоксов, что у квартиры.
- Цена и условия сделки — полностью как у квартиры (цена ₽/мес, торг, залог, комиссия, мин. срок, коммунальные платежи, онлайн-показ).

## Коммерческая

Тип объявления: только Продать / Сдать длительно.

### Базовая форма (без выбранного назначения)
- Адрес — город + `текст`.
- Назначение — `radio` (11 значений): **Для офиса, Торговое помещение, Свободное назначение, Общепит, Автосервис, Готовый бизнес, Юридический адрес, Склад, Земля комм. назначения, Гостиница, Производство**.
- Описание — `текст` (секция «Описание», без чекбоксов удобств).
- Цена и условия сделки: Цена ₽/мес; Онлайн-показ; **Тип сделки** — `radio`: Прямая аренда, Субаренда, Продажа права аренды; **Налог** — `radio`: НДС, УСН; **Обеспечительный платёж, %** — `число`.

Выбор назначения раскрывает дополнительные секции; набор полей зависит от подтипа.

### Подтип «Для офиса»
- Тип здания — `radio`: Бизнес-центр, Складское помещение, Торговый центр, Отдельно стоящее здание, Помещение в жилом доме.
- Об объекте: Этаж — два `числа` («из»); Площадь, м² — `число`; Сколько комнат — `число`; Вход — `radio`: Отдельный, Общий; Ремонт — `radio`: Косметический, Евро, Дизайнерский, Требуется.
- Удобства (6 чекбоксов): Интернет, Кондиционер, Вентиляция, Пожарная сигнализация, Доступ на объект 24/7, Пропускная система.
- Цена: к базовому блоку добавляются «Дополнительно» (чекбоксы: Есть залог, Включены коммунальные услуги, Возможен торг, Включена уборка, Включена электроэнергия), Предоплата % и Комиссия агента %.

### Подтип «Торговое помещение»
- Возможное назначение — `checkbox`: Помещение для банка, Продуктовый магазин, Шоурум, Турагентство, Медицинский центр, Салон красоты.
- Тип здания — тот же список из 5 значений.
- Об объекте: Этаж («из»), Площадь, Сколько комнат, Вход, Ремонт — как у офиса.
- Удобства (4 чекбокса): Интернет, Кондиционер, Вентиляция, Пожарная сигнализация.
- Цена — как у офиса.

### Подтип «Общепит»
- Тип здания — тот же список из 5 значений.
- Об объекте: Этаж («из»), Площадь, Сколько комнат, Вход — **без «Ремонта»**.
- Удобства (3 чекбокса): Кондиционер, Вентиляция, Пожарная сигнализация.
- Цена — как у офиса.

### Подтип «Склад»
- Возможное назначение — `checkbox`: Алкогольный склад, Овощехранилище, Фармацевтический склад.
- Тип здания — тот же список из 5 значений.
- Об объекте: только Площадь, м² и Вход (Отдельный / Общий) — **без Этажа, «Сколько комнат» и Ремонта**.
- Удобства (9 чекбоксов): Кондиционер, Вентиляция, Пожарная сигнализация, Офис на складе, Грузовой лифт, Подъезд для фур, Пандус, Ветка ж/д, Логистика.
- Цена — как у офиса.

### Подтип «Земля комм. назначения»
- Об объекте: только **Площадь участка** — `число` + `select`: Соток (по умолчанию), Гектаров.
- Без «Типа здания», без чекбоксов удобств (секция «Описание» — только текст).
- Цена — базовый блок (Цена ₽/мес, Онлайн-показ, Тип сделки, Налог, Обеспечительный платёж %); **без** «Дополнительно», Предоплаты и Комиссии агента.

### Не проверенные подтипы
Свободное назначение, Автосервис, Готовый бизнес, Юридический адрес, Гостиница, Производство — формы не сняты; у них свои вариации полей (см. «Пробелы»).

Отдельного типа «Участок» при аренде («Сдать длительно») **нет** — он доступен только при «Продать» (там список типов: Квартира, Комната, Дом / дача, Гараж, Коммерческая, Участок). Ближайшие аналоги в аренде: подтип «Земля комм. назначения» у Коммерческой и секция «Участок» внутри «Дом / дача».

### Ключевые отличия наборов полей
1. **Квартира ↔ Комната** почти идентичны: у комнаты нет «Студии» и «1» в «Комнат», нет жилой площади и секции «Планировка», зато добавляются «Комнат в сделке» и «Покрытие пола».
2. **Дом/дача** — совсем другой домен: участок (площадь в сотках/гектарах, тип ИЖС/Садовый/Фермерский), материал и тип дома, санузел/душ «в доме/на улице/отсутствует»; нет комнат, ремонта, этажа, парковки.
3. **Гараж** — минимальный набор: тип, материал, правовой статус, ГСК, площадь; без «О доме»/«О квартире».
4. **Коммерческая** — собственная ось «Назначение» (11 подтипов), от которой зависят остальные поля; уникальные поля сделки: Тип сделки (прямая аренда/субаренда/продажа права аренды), Налог (НДС/УСН), Обеспечительный платёж %.
5. **Блок «Цена и условия»** имеет два семейства: «квартирное» (торг-radio, залог суммой + %, комиссия + radio, мин. срок, коммунальные платежи-radio) у Квартиры и Комнаты; «свёрнутое» (чекбоксы «Дополнительно» + Предоплата % + Комиссия агента %) у Дома, Гаража и Коммерческой.
6. «Сдать посуточно» есть только у Квартиры, Комнаты и Дома/дачи.

## Пробелы и ограничения

1. **Обязательность полей не зафиксирована**: звёздочки/aria-required в accessibility-снапшотах не отображаются. Известно только, что пустые/невалидные поля помечаются «Некорректное значение поля», а сбоку показывается процент заполнения. Для точного списка обязательных полей нужен проход с визуальной проверкой или попытка публикации (требует авторизации).
2. **Коммерческая: не сняты подтипы** Свободное назначение, Автосервис, Готовый бизнес, Юридический адрес, Гостиница, Производство — у каждого свои «Возможное назначение»/удобства/состав «Об объекте».
3. **Значения по умолчанию**: зафиксированы «Только счётчики» (коммунальные платежи у квартиры/комнаты), «Включить умную сортировку» (везде), «Соток» (единицы площади участка), «Охрана» отмечена у гаража; дефолты могут зависеть от сохранённого состояния браузера.
4. **Поле «Комнат в сделке» у комнаты** снято в disabled-состоянии (зависит от «Комнат»); диапазон доступных значений после выбора не проверялся (видны 1–6).
5. **Минимальный срок аренды** у квартиры/комнаты — checkbox «Есть»; появляется ли при включении поле количества месяцев, из снапшота не видно.
6. **Флоу посуточной аренды не исследовался** (задача — длительная аренда).
7. Авторизация/капча в этой сессии не потребовались; форма доступна анонимно целиком, кроме блока «Контакты» и публикации.
