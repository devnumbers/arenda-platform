# CONTEXT.md

This file is a domain glossary. It intentionally avoids implementation details.

## Собственник / Owner

Пользователь сервиса, который управляет объектами, арендами, операциями, регулярными операциями, SMS-настройками и подпиской.

## Админ / Admin

Внутренний пользователь сервиса для поддержки. Админ не ведет объекты и финансы за собственника, но может вести собственные тестовые данные для проверки тарифной логики.

## Объект / Property

Минимальная сдаваемая единица, по которой можно заключить аренду и вести денежные записи.

## Арендатор / Tenant Contact

Необязательный контакт собственника. В MVP арендатор не является пользователем сервиса.

## Аренда / Lease

Учетная запись условий аренды по одному объекту.

## Открытая аренда / Open Lease

Аренда в статусе `Ожидает начала`, `Активная` или `Требует действия`.

## Операция / Operation

Денежная запись по объекту: доход или расход на прошлую, текущую или будущую дату.

## Регулярная операция / Recurring Operation

Шаблон повторяющейся денежной записи по объекту. Регулярная операция создает обычные операции на ограниченный горизонт вперед.

## Категория дохода / Income Category

Фиксированный вид доходной операции по объекту: арендная плата или прочий доход.

## Категория расхода / Expense Category

Фиксированный вид расходной операции по объекту: ЖКХ, ремонт, налог или прочее.

## Оплата подписки / Subscription Payment

Денежное событие оплаты тарифа собственника через платежного провайдера. Оплата подписки относится к подписке и не является финансовой операцией по объекту.

## Платежи / Payments Section

Пользовательский раздел интерфейса для операций и регулярных операций по объектам. Это не отдельная доменная сущность и не оплата подписки.

## Залог / Deposit

Справочная сумма обеспечения в условиях аренды. В MVP залог не является отдельной финансовой сущностью.

## Активный объект / Active Property

Неархивный объект. Активные объекты считаются в тарифных лимитах.

## Архивный объект / Archived Property

Объект, скрытый из активных списков и доступный только для просмотра истории.

## Тариф / Tariff Plan

План подписки, который задает лимит активных объектов и стоимость.

## Подписка пользователя / User Subscription

Состояние тарифа пользователя. Подписка может быть платной для собственника или служебной для админа.
