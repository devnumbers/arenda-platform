# Billing

Тарифы, подписки, способы оплаты и интеграция с Т-Кассой. Отдельный контекст от Rental: оплата подписки — это не финансовая операция по объекту.

## Language

### Подписка

**Тариф / Tariff Plan**:
План подписки, который задаёт лимит активных объектов и стоимость.
_Avoid_: план, пакет

**Подписка пользователя / User Subscription**:
Состояние тарифа пользователя. Подписка может быть платной для собственника или служебной для админа.
_Avoid_: аккаунт-план

**Оплата подписки / Subscription Payment**:
Денежное событие оплаты тарифа собственника через платёжного провайдера. Относится к подписке и не является финансовой операцией по объекту.
_Avoid_: платёж за тариф

**Статусы подписки / Subscription Status**:
- `active` — подписка оплачена или бесплатная, изменения данных разрешены.
- `grace` — не удалось списать платёж за продление, отсрочка для повторной попытки или смены способа оплаты; изменения данных временно разрешены.
- `cancelled` — подписка отменена пользователем; автопродление отключено, но изменения данных доступны до конца оплаченного периода, восстановление возможно через оплату тарифа.
_Avoid_: состояние подписки

**Автопродление / Auto Renew**:
Настройка подписки, при которой по окончании оплаченного периода списывается плата за тот же тариф и период продлевается.
_Avoid_: автосписание, пролонгация

**Апгрейд / Upgrade**:
Смена тарифа на более дорогой. Выполняется сразу после успешной оплаты, стоимость рассчитывается по полной цене нового тарифа, срок действия отсчитывается от момента оплаты.
_Avoid_: повышение тарифа

**Даунгрейд / Downgrade**:
Смена тарифа на более дешёвый. Не требует немедленной оплаты, вступает в силу в конце уже оплаченного периода. При даунгрейде, если количество активных объектов превышает лимит нового тарифа, система архивирует лишние объекты.
_Avoid_: понижение тарифа

**Льготный период / Grace Period**:
Срок после неудачного автосписания, в течение которого подписка остаётся в статусе `grace` и пользователь может обновить способ оплаты. По истечении льготного периода подписка переходит на базовый тариф, а избыточные объекты автоматически архивируются.
_Avoid_: отсрочка, пробный период

### Способы оплаты

**Способ оплаты / Payment Method**:
Сохранённый платёжный инструмент пользователя (например, привязанная карта). Для каждого пользователя может быть несколько способов оплаты, но активным — только один. Используется для автопродления подписки.
_Avoid_: карта, платёжный инструмент

### Т-Касса (термины провайдера)

**CC (Card Credentials)**:
Платёж по введённым карточным данным; родительский платёж CC/COF-связки.
_Avoid_: платёж по карте

**COF (Credentials on File)**:
Платёж по сохранённым реквизитам (RebillId).
_Avoid_: платёж по токену

**CIT (Customer-Initiated Transaction)**:
Операция, инициированная покупателем.
_Avoid_: инициативный платёж

**MIT (Merchant-Initiated Transaction)**:
Операция, инициированная мерчантом (например, автопродление подписки).
_Avoid_: автоматический платёж

**RebillId**:
Идентификатор сохранённых реквизитов в Т-Кассе, выдаётся после родительского платежа с `Recurrent=Y`.
_Avoid_: токен реквизитов

**PaymentId**:
Идентификатор платежа в Т-Кассе, выдаётся в ответе `Init`.
_Avoid_: идентификатор транзакции

**RequestKey**:
Идентификатор запроса на привязку карты в Т-Кассе, возвращается `AddCard` и приходит в add-card webhook.
_Avoid_: ключ привязки

**NotificationURL**:
URL мерчанта для webhook-уведомлений Т-Кассы о статусах платежа.
_Avoid_: callback URL, webhook endpoint
