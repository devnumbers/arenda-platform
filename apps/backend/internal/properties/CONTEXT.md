# Rental

Супер-контекст: properties + leases + notifications (ADR 0029). Три bounded context образуют bidirectional циклы на уровне domain и application слоёв, поэтому их ubiquitous language неразделим до разрыва через ports. Охватывает объекты, аренды, операции, регулярные операции, категории, залоги, напоминания и настройки уведомлений.

## Language

### Объекты

**Объект / Property**:
Минимальная сдаваемая единица, по которой можно заключить аренду и вести денежные записи.
_Avoid_: квартира, жильё, недвижимость

**Характеристики объекта / Property Attributes**:
Пер-типовые типизированные характеристики объекта: число комнат, площади, этаж, год постройки и т.п. Набор характеристик определяется типом объекта (всего 10 типов). Все характеристики необязательные. Ключи и значения — на английском; русские подписи показываются на фронте и в админке.
_Avoid_: атрибуты, параметры, спецификация

**Контакт объекта / Property Contact**:
Произвольный контакт, прикреплённый к конкретному объекту: сантехник, управляющая компания, консьерж, диспетчер. Принадлежит ровно одному объекту, не связан с арендаторами и арендами, удаляется вместе с объектом. Не является пользователем сервиса. Не путать с контактом арендатора — это раздельные сущности, одна персона может быть и тем и другим независимо.
_Avoid_: контакт, связь

**Арендатор / Tenant Contact**:
Необязательная справочная запись собственника о съёмщике (контакт арендатора). В MVP арендатор не является пользователем сервиса.
_Avoid_: жилец, наниматель

**Активный объект / Active Property**:
Неархивный объект. Активные объекты считаются в тарифных лимитах.
_Avoid_: текущий объект

**Архивный объект / Archived Property**:
Объект, скрытый из активных списков и доступный только для просмотра истории.
_Avoid_: удалённый объект, выключенный объект

**Удаление объекта / Property Deletion**:
Безвозвратное удаление объекта. Режимы и ограничения — ADR 0025 (docs/adr/0025-property-deletion-modes.md). Запрещено при открытой аренде.
_Avoid_: стирание, очистка объекта

### Аренды

**Аренда / Lease**:
Учётная запись условий аренды по одному объекту.
_Avoid_: договор, контракт

**Открытая аренда / Open Lease**:
Аренда в статусе `Ожидает начала`, `Активная` или `Требует действия`.
_Avoid_: активная аренда (двусмысленно)

**Залог / Deposit**:
Справочная сумма обеспечения в условиях аренды. В MVP залог не является отдельной финансовой сущностью.
_Avoid_: обеспечительный платёж, депозит

### Операции

**Операция / Operation**:
Денежная запись по объекту: доход или расход на прошлую, текущую или будущую дату. Проходит через статусы: `pending`, `overdue`, `unconfirmed`, `paid` (расход), `received` (доход).
_Avoid_: проводка, транзакция, платёж

**Запланированная операция / Pending Operation**:
Операция, созданная в статусе `pending` и ещё не выполненная.
_Avoid_: будущая операция

**Просроченная операция / Overdue Operation**:
Запланированная операция, дата которой наступила, а статус так и не стал выполненным.
_Avoid_: пропущенная операция

**Неподтверждённая операция / Unconfirmed Operation**:
Операция, созданная задним числом (датой в прошлом) в статусе `unconfirmed`. Требует явного подтверждения собственником и никогда не переходит в `overdue` автоматически.
_Avoid_: черновая операция

**Выполненная операция / Completed Operation**:
Операция, отмеченная собственником как выполненная: `paid` (расход) или `received` (доход).
_Avoid_: закрытая операция

**Регулярная операция / Recurring Operation**:
Шаблон повторяющейся денежной записи по объекту. Создаёт обычные операции на ограниченный горизонт вперёд.
_Avoid_: автоплатёж, повторяющийся платёж

**Категория дохода / Income Category**:
Фиксированный вид доходной операции по объекту: арендная плата или прочий доход.
_Avoid_: тип дохода

**Категория расхода / Expense Category**:
Фиксированный вид расходной операции по объекту: ЖКХ, ремонт, налог или прочее.
_Avoid_: тип расхода, статья расхода

**Платежи / Payments Section**:
Пользовательский раздел интерфейса для операций и регулярных операций по объектам. Это не отдельная доменная сущность и не оплата подписки.
_Avoid_: раздел финансов, кошелёк

_Известный дрейф_: код аренд использует имена `PaymentDay` и `nextPaymentDate` (`internal/leases/domain`), хотя «платёж» зарезервирован за процессингом (ADR 0036, docs/adr/0036-fintech-domain-language.md). В новом коде и текстах «платёж» в домене аренды не использовать; переименование — отдельная задача.

### Финансовый учёт

Продукт совмещает оба метода учёта (ADR 0036): операции планируются по методу начисления, а выполнение операции — кассовый факт.

**Доход / Income**:
Заработанное арендным бизнесом за период; в продукте — доходная операция.
_Avoid_: поступление, платёж

**Расход / Expense**:
Потраченное, чтобы получить доход; в продукте — расходная операция.
_Avoid_: трата, списание

**Арендная плата / Rent**:
Основная категория дохода: сумма, регулярно причитающаяся от арендатора по условиям аренды.
_Avoid_: рента, квартплата

**Прибыль / Profit**:
Доходы минус расходы за период. Вычисляется из операций, не хранится как сущность.
_Avoid_: выручка, оборот

**Денежный поток / Cash Flow**:
Реальное движение денег за период; считается по выполненным операциям (`received` / `paid`).
_Avoid_: кэшфлоу

**Кассовый метод / Cash Basis**:
Признание дохода и расхода по факту движения денег. В продукте соответствует выполненным операциям.
_Avoid_: учёт по оплате

**Метод начисления / Accrual Basis**:
Признание дохода и расхода по моменту возникновения обязательства, независимо от оплаты. В продукте соответствует запланированным и просроченным операциям.
_Avoid_: учёт по счетам

**Дебиторская задолженность / Receivables**:
Долг арендатора собственнику — просроченные доходные операции (`overdue`).
_Avoid_: дебиторка

**Кредиторская задолженность / Payables**:
Долг собственника — просроченные расходные операции (`overdue`).
_Avoid_: кредиторка

**Аванс (Предоплата) / Advance Payment**:
Арендная плата, полученная до периода, который она покрывает. Отдельно не моделируется — записывается обычной доходной операцией.
_Avoid_: предварительная оплата

**Незаработанный доход / Unearned Revenue**:
Аванс, период которого ещё не наступил; по методу начисления — обязательство. В продукте отдельно не моделируется.
_Avoid_: отложенный доход

### Уведомления

**Настройки уведомлений / Notification Preferences**:
Пользовательская настройка отправки напоминаний по типам. Управляется собственником в профиле, на странице «Мои данные», секция «Уведомления». См. ADR 0022 (docs/adr/0022-notification-preferences.md).
_Avoid_: настройки SMS, настройки оповещений

**Разрешение на тип напоминания / Reminder Type Permission**:
Флаг разрешения отправки для одного типа напоминаний: напоминание об операции, просроченная операция, окончание аренды, аренда требует действия. Работает по модели opt-out: по умолчанию все типы разрешены. Отозванный тип не отправляется; напоминание, пропущенное из-за запрета, получает терминальный статус `skipped`. Разрешение привязано к типу и действует на все каналы отправки.
_Avoid_: подписка на уведомления, флаг канала
