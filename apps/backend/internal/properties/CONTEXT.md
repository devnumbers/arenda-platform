# Properties

Bounded context объектов. После удаления домена аренд и Операций (ADR 0046, тикет #436) контекст «только про объект»: карточка, фото, атрибуты, архив. Термины занятости (аренды, операции, сводки) из языка контекста ушли вместе с доменом; контакты ушли в отдельный контекст contacts (ADR 0054).

## Language

**Объект / Property**:
Минимальная единица учёта платформы: карточка объекта с атрибутами и фото. Контакты объекта живут в отдельном контексте contacts (ADR 0054); домен платежей (контекст payments, ADR 0047) проектируется поверх объектов отдельными спеками.
_Avoid_: квартира, жильё, недвижимость

**Характеристики объекта / Property Attributes**:
Пер-типовые типизированные характеристики объекта: число комнат, площади, этаж, год постройки и т.п. Набор характеристик определяется типом объекта (всего 10 типов). Все характеристики необязательные. Ключи и значения — на английском; русские подписи показываются на фронте и в админке.
_Avoid_: атрибуты, параметры, спецификация

**Фото объекта / Property Photo**:
Фотография карточки объекта. Хранится в объектном хранилище, метаданные — в БД; до 10 фото по 5 МиБ на объект.
_Avoid_: изображение, картинка

**Активный объект / Active Property**:
Неархивный объект. Активные объекты считаются в тарифных лимитах.
_Avoid_: текущий объект

**Архивный объект / Archived Property**:
Объект, скрытый из активных списков и доступный только для просмотра истории.
_Avoid_: удалённый объект, выключенный объект

**Основной объект / Primary Property**:
Глобальный признак «наверху списков» (карта #573, тикет #577; переосмыслен в терминах «основного» резолюцией #584): основной объект поднимается и в главном списке «Объекты», и на странице «Платежи объектов», и в сортировке «По статусу» всегда первый. Признак ставится на объекте — не пер-пользовательский; основных объектов может быть несколько. Хранится как `pinned_at`: NULL — не основной, момент времени — основной с того момента; порядок среди основных — по времени (первый отмеченный выше, повторная отметка время не меняет). Права — как у правки объекта (ADR 0028 `CanEdit`: владелец и полный доступ). Архивация снимает признак в том же обновлении (возвращённый из архива объект не основной); удаление уносит его вместе со строкой. Контракт API не переименовывается — поле и эндпоинт остаются `pinned_at` / `PUT /properties/{id}/pin` (решение тикета #585).
_Avoid_: пин, булавка, закреплённый, закрепление, избранное (избранное — про платежи)

**Занятость объекта / Property Occupancy**:
Вычисляемое состояние объекта из его единственной незавершённой аренды (подошла к концу / активная / будущая / нет) против «сегодня владельца» (ADR 0048); резолюция #584. Канон для группировки сортировки «По статусу», бейджей карточки и красной точки. Статусы без аренды — `none`; статус самого объекта (активный / на ремонте / архивный) — жизненный цикл, не занятость: объект с арендой на ремонте остаётся в своей арендной группе. Просрочка платежей для красной точки — язык payments (overdue), занятость её не дублирует.
_Avoid_: статус объекта (это жизненный цикл), загруженность, состояние аренды

**Удаление объекта / Property Deletion**:
Безвозвратное удаление объекта. Режимы и ограничения — ADR 0025 (docs/adr/0025-property-deletion-modes.md); режим `detach` дополнительно приостанавливает биллинг-жизненный цикл объекта перед удалением.
_Avoid_: стирание, очистка объекта

**Шаринг объекта / Property Sharing**:
Совместный доступ к объекту через участников и приглашения (контекст access). Роль актёра на объекте видна в карточке; превысившие лимит участника приостанавливаются.
_Avoid_: совместное владение
