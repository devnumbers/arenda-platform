# Access

Совместный доступ к объектам, роли участников и правила производного доступа к данным объекта. Управляет тем, кто может видеть и редактировать объекты и их производные данные.

## Language

**Совместный доступ к объекту / Property Sharing**:
Доступ пользователя к чужому объекту и всем его данным, выданный владельцем объекта по email с ролью «Полный доступ» или «Просмотр». Объект с совместным доступом занимает слот в тарифном лимите получателя как собственный активный объект; при нехватке лимита доступ создаётся приостановленным. Доступ активируется сразу, без подтверждения получателем; для незарегистрированной почты — при регистрации аккаунта с этой почтой. Число участников одного объекта не ограничено.
_Avoid_: шеринг, расшаренный объект, sharing

**Участник объекта / Property Member**:
Пользователь, получивший совместный доступ к объекту. Участник не владелец: его доступ может быть отозван владельцем или участником с полным доступом, а также прекращён им самим (самовыход). Участник видит все данные объекта без исключений.
_Avoid_: гость, соарендатор

**Производный доступ к данным объекта / Derived Object Access**:
Правило: доступ к данным, производным от объекта, определяется доступом к самому объекту. Пользователь с ролью на объекте получает соответствующий доступ ко всем производным данным этого объекта. Первые производные данные после удаления аренд (спека #434) — платежи и операции контекста payments (ADR 0047). См. ADR 0028 (docs/adr/0028-object-data-access-model.md).
_Avoid_: наследуемый доступ, каскадный доступ

**События жизненного цикла доступа / Access Lifecycle Events** (карта #734, #751):
Переходы доступа — активация приглашения, отзыв, слотовая пауза и восстановление, самовыход — покидают контекст как события через порт `AccessEventPublisher` (канон grace-events: событие публикуется строго после коммита вызвавшей транзакции; координатор слотов, работающий внутри чужих транзакций, публикует в транзакции — форма заменённых им писем issue #162). События чистые: только id, флаги и мгновения; снимки имён — словарь уведомлений, резолвятся при публикации. Прямые lifecycle-письма по этим переходам снесены; прямыми остались только invite-письмо незарегистрированному адресату и «объект удалён».
