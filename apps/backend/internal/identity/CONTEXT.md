# Identity

Accounts, sessions, and user roles for Arenda Platform. Two user roles thread through every other context.

## Language

**Собственник / Owner**:
Пользователь сервиса, который управляет объектами, арендами, операциями, регулярными операциями, SMS-настройками и подпиской.
_Avoid_: аккаунт, клиент

**Админ / Admin**:
Внутренний пользователь сервиса для поддержки. Админ не ведёт объекты и финансы за собственника, но может вести собственные тестовые данные для проверки тарифной логики.
_Avoid_: модератор, оператор

**Сессия / Session**:
Server-side непрозрачный токен доступа, хранимый в PostgreSQL и доставляемый через `HttpOnly`-cookie (ADR 0004). Живёт по sliding-окну: каждое использование продлевает срок на базовый TTL (7 дней), но не дольше абсолютного максимума (30 дней от создания). ADR 0011.
_Avoid_: токен, ключ

**Логин-код / Login code**:
Одноразовый код подтверждения, отправляемый на email. Имеет TTL (см. `domain.LoginCodeTTL`), используется один раз, хранится только в виде хеша. Используется для двух целей: вход в систему (login) и подтверждение смены телефона (phone change).
_Avoid_: пароль, SMS-код (доставка сейчас по email)

**Окно попыток / Attempt window**:
Sliding 30-минутное окно, считающее неудачные попытки ввода логин-кода. После 15 неудач номер блокируется до истечения окна.
_Avoid_: лимит, rate-limit (это доменное правило, а не транспортное)
