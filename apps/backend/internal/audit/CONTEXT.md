# Audit

Журнал действий пользователей, админов и системы. Все контексты пишут сюда.

## Language

**Журнал действий / Audit Log**:
Персистентный журнал «кто, когда, что сделал»: действия пользователей, админов и системы. Записи пишутся в транзакции бизнес-операции. Просмотр — в админке: раздел «Журнал действий» и вкладка у пользователя. См. ADR 0020 (docs/adr/0020-audit-log.md). Граница: продуктовая лента для пользователей — это «История действий» контекста История (ADR 0061), не этот журнал.
_Avoid_: лог событий, event log
