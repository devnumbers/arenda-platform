# Tasks

Bounded context задач по объекту: правило порождает вхождения-задачи на конкретные даты, задачу выполняют вручную; просрочка и «без срока» — вычисляемые состояния. Паттерн «правило → вхождения» перенят у Payments (тик, материализация, проекция); слова Payments («Платёж», «Операция») не занимаются. «Объект» не переопределяется — см. properties/CONTEXT.md.

## Language

**Правило / Task rule**:
Настройка на объекте, порождающая задачи: название (обязательно), комментарий, срок — дата опциональна, время опционально и только при дате — и повтор: один раз, каждый день, каждую неделю, каждый месяц, каждый год. Разовое правило порождает одну задачу. Само по себе не бывает выполнено, просрочено или без срока — это состояния его задач.
_Avoid_: задача (когда имеется в виду правило), шаблон, регулярная задача, повторяющаяся задача, напоминание

**Задача / Task**:
Вхождение правила в конкретную дату — единица выполнения: то, что видят во вкладках Активные и Выполненные и что выполняют вручную. Несёт снимок названия и комментария правила на момент материализации: правка правила меняет будущие материализации, а не уже созданные задачи. Просроченной и «без срока» бывает только она.
_Avoid_: напоминание, дело, экземпляр, операция

**Активная задача / Active task**:
Материализованная задача, которую ещё не выполнили; просрочка — её вычисляемое состояние. Содержимое вкладки «Активные».
_Avoid_: открытая, незакрытая, висящая

**Выполненная задача / Completed task**:
Задача, которую выполнили вручную: «выполнить/выполнено», не «закрыть/оплатить». Дата выполнения — факт и может не совпадать со сроком; отдельного термина для опоздания нет. Выполнение обратимо, пока правило живо: «Отменить выполнение» возвращает задачу в активные, график правила не трогает. Выполненные задачи образуют журнал выполнений и остаются даже после удаления правила.
_Avoid_: закрытая, оплаченная, завершённая (словарь Payments), «выполнена с опозданием»

**Просрочка / Overdue**:
Вычисляемое состояние задачи: запланирована, но срок уже прошёл. Не хранится как статус. Граница «прошёл» — момент срока с точностью до минут, включительно (15:13 → просрочена в 15:13), для задачи со временем; конец суток — для даты без времени (#496). Вычисляется сервером на чтении по текущему моменту в поясе собственника объекта (ADR 0048), секунды не участвуют.
_Avoid_: хранимый статус «просрочен», задолженность

**Без срока / Undated**:
Вычисляемая метка задачи, созданной без даты: она не наступает и не просрочивается никогда — ждёт в активных. Время без даты невозможно.
_Avoid_: отложенная, «на потом», вечная

**Тик / Tick**:
Идемпотентный прогон материализации: правила + «сегодня» → задачи (пауз нет — в отличие от Payments). «Сегодня» — дата в часовом поясе собственника объекта (ADR 0048). Запускается ежечасным фоновым воркером и внутри мутаций контекста; чистое чтение не тикает.
_Avoid_: крон, джоба

**Материализация / Materialization**:
Создание задач по правилам: все наступившие (дата ≤ сегодня) и ровно одно следующее будущее. Задача без даты материализуется сразу при создании правила. Дальнейший график — проекция.
_Avoid_: генерация всего графика вперёд (будущее — проекция)

**Проекция / Projection**:
Вычисляемый график будущих задач после материализованного следующего: без записей в БД и без статусов.
_Avoid_: виртуальные задачи

**Удалённое правило / Deleted rule**:
Правило после удаления: задач больше не порождает, все его невыполненные задачи исчезают — плановые, просроченные и материализованное «следующее будущее» (аналога keep_overdue из Payments нет: у задач нет долга). Выполненные задачи остаются в журнале выполнений. Статуса-надгробия у задач нет: поединичного удаления задач нет — расписание правится на уровне правила, а удалённое правило тик больше не читает.
_Avoid_: архивное правило, отключённое правило, отменённая задача
