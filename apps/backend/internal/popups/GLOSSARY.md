# Popups

Онбординг-попапы и серверные маркеры их просмотра. Гарантирует показ попапа ровно один раз на всех устройствах.

## Language

**Онбординг-попап / Onboarding Popup**:
Модальное окно, показываемое пользователю ровно один раз при входе в кабинет. Первый такой попап — о напоминаниях: текст, чекбоксы типов напоминаний и подсказка о дальнейшей настройке в «Моих данных». Закрывается только кнопкой «Сохранить». См. ADR 0023 (docs/adr/0023-popup-views.md).
_Avoid_: приветственное окно, тур

**Просмотр попапа / Popup View**:
Серверный маркер того, что пользователь видел конкретный попап, по паре (пользователь, ключ попапа). Гарантирует показ ровно один раз на всех устройствах. См. ADR 0023 (docs/adr/0023-popup-views.md).
_Avoid_: флаг просмотра, отметка попапа
