# Чек-лист: цвета Figma-файла → Variables `--dl-*`

Цель: перевести цвета файла «📌 Рентли. Новые экраны сервиса» на Figma
Variables, чтобы `get_variable_defs` официального MCP отдавал агенту токены
дословно. Сейчас в файле **0 переменных** — весь цвет сырым hex. Значения уже
канонизированы в `apps/frontend/shared/styles/tokens.css` (`--dl-*`,
палитра совпадает) — задача именно назвать и разложить их по переменным в
Figma. Перенос — ручная работа владельца/дизайнера; решение о подходе —
владелец 2026-09-08 (только цвета, остальную гигиену файла не трогаем).

## Шаги в Figma

1. Создать коллекцию переменных (например «DL»), режим Default.
2. Завести цветовые переменные по таблице ниже.
3. У каждой переменной в панели переменных задать **code syntax**: имя
   `--dl-…` — тогда экспорт и MCP возвращают токен дословно.
4. Присвоить переменные заливкам: выделить слой → Select same → Fill.
   Начать с компонент-сетов (Button, Icon Button, Category Icon,
   DesktopMenuButton), дальше по экранам.
5. Иконкам (`Icon/*`) переменные не назначать: их краски при экспорте
   нормализуются в `currentColor` (DESIGN.md §10).

## Пробелы — вопросы владельцу

- **`#FFB900`** (текст бейджа «Объект на ремонте», экран 1603:89079) —
  токена `--dl-*` нет; легаси `--color-warning: #EBB800` — другое значение.
  Завести `--dl-warning: #FFB900` (+ подложка?) или оставить hex?
- Градиентные `Icon/Color/*` и `notification-dot` — запечённые исключения
  (DESIGN.md §10), переменными не накрывать.
- Легаси-палитра старых экранов (`#1e1e1e`, `#f1f3f6`, …) — не трогаем:
  переменные только для слоя `--dl-*`.

## Порядок

Начать с цветов пилотного экрана «Объекты» (нода 1603:89079): `#FFFFFF`,
`#171A1C`, `#6F787C`, `#F3F4F6`, `#2B7FFF`, `#FB2C36`, `#FFB900` — затем
компонент-сеты и остальные экраны.
