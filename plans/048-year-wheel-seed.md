# 048 — Колесо годов: стартовый посев по физике флика, не по запасу

- **Status**: DONE
- **Baseline**: план 047 (хром/модалка DONE)
- **Severity**: MEDIUM (решение владельца, feel-check 16.10–17.10: «пикер так долго открывается»)
- **Origin**: карта #1437, догонка feel-check владельца; замер на живом стенде 17.10
- **Estimated scope**: years-window.ts, month-year-picker.tsx, тесты, ~40 строк

## Problem

Шит «Месяц и год» открывается 858–1147мс против 140–218мс у лёгких
модалок (замер на прод-сборке стенда, 3+3 замера). Причина: стартовый
посев годового колеса на 400 лет в прошлое (`YEARS_BACKWARD_EXTENSION`,
решение 13.10 «первый флик назад никогда не встречает стены») монтирует
401 ряд `<li>`, и каждый ряд несёт scroll-driven каскад
(`animation-timeline: view()`). Регистрация 401 анимаций при монтировании
стоит ~650–800мс (A/B на стенде: с каскадом 858–1147мс, без — 304–335мс),
DOM из 401 ряда — ещё ~300мс против ~150мс лёгкой модалки.
`content-visibility` на рядах проверен и не помогает (1160мс).

Физика флика уже выведена в wheel-edge.ts: зона триггера 80 рядов,
максимальный флик 54 ряда. Стартовый посев обязан гарантировать только
«первый жёсткий флик назад без стены» — для этого хватает 134 года
(80 + 54), а не 400; доращивание в паузе (+400) уже стоит и держит стену
недостижимой дальше.

Решение владельца 17.10: посев 400 → 134, шаг доращивания остаётся 400,
каскад не трогается.

## Target

**Шаг 1 — `shared/ui/design/years-window.ts`**: новая константа
`YEARS_INITIAL_BACKWARD_SEED = WHEEL_NEAR_EDGE_ROWS + WHEEL_MAX_FLING_ROWS`
(134, вывод из wheel-edge — в комментарии); `YEARS_BACKWARD_EXTENSION`
остаётся шагом доращивания (400), докстринг переписан: сид и шаг — разные
вещи с разными требованиями (сид — «первый флик без стены + зона входит»,
шаг — «после компенсации выйти из зоны», инвариант юнит-теста живёт).

**Шаг 2 — `shared/ui/design/month-year-picker.tsx`**: начальный
`yearsStart` сеется от `YEARS_INITIAL_BACKWARD_SEED` (ветка max без min —
пикер периода операций, история); доращивание `onNearStart` остаётся на
`YEARS_BACKWARD_EXTENSION`.

**Шаг 3 — тесты**: `years-window.test.ts` — ассерты на сид (134 = сумма
констант wheel-edge; строго больше зоны и максимального флика; шаг больше
сида) — красный до правки; `e2e/wheel-picker.spec.ts` — ожидание первого
ряда ленты `2026 − 134` вместо `2026 − 400`, серия фликов и гард стены
остаются (поведение «стены нет» не меняется — меняется глубина ленты).
