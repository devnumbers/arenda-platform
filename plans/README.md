## Порядок исполнения

001 → 002 → 004 → 003.

- 001 и 002 — визуальные, быстрые, независимые.
- 004 — изолированная добавка (новый модуль + реф).
- 003 — последний: единственный с риском (пер-кадровые записи scrollTop
  в scroll-snap-контейнер); его гейт — e2e, фолбэк прописан в плане.

Зависимостей по файлам нет, но все четыре правят `wheel-picker.tsx` —
исполнять строго последовательно, не параллелить executor'ов.

## Верификация после всех планов

- `make frontend-test` — зелёный.
- `make frontend-e2e TESTS='-g WheelPicker'` (Docker) — 10 тестов зелёные.
- Feel-check владельца: реальный iPhone (тап-фидбек, лонг-пресс, SDA
  потемнение — iOS 26) и реальный Android (тики без гула); slow-mo
  скринрекорд колеса для проверки ступеньки цвета (план 002).
