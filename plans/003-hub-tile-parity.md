## Problem

Скелетон секции хаба рисует плитки `h-[132px] w-[168.5px]`
(`widgets/payments/ui/payments-global-screen.tsx:730-731`), живая
`PaymentCardButton` — hug: `p-4`(16) + иконка-ряд 44 + `pb-3`(12) + заголовок
`text-xs` 13/15 в 1–2 строки + `gap-1`(4) + подпись 15 + `p-4`(16) =
**122px** (заголовок в строку) или **137px** (в две). 132 не равен ничему:
при каждой загрузке хаба 4 секции доезжают на 5–10px (до ~40px рефлоу
страницы) — разрыв паритет-канона #605 «контент занимает место скелетона».

## Target

Высота плитки фиксированная и одинаковая у скелетона и карточки: **137px**
(вместимость двухстрочного заголовка — худший случай контента).

```tsx
/* payment-card-button.tsx:60 — target */
'flex h-[137px] w-[168.5px] shrink-0 cursor-pointer flex-col rounded-card bg-surface-muted p-4 outline-none',
/* нижний блок прижимается к дну: */
<span className="mt-auto flex w-full flex-col gap-1 text-xs font-medium">
```

```tsx
/* payments-global-screen.tsx:730 — target */
<Skeleton className="h-[137px] w-[168.5px] shrink-0" />
```

Плитки секции выравниваются в единый ряд (иконка сверху, текст у дна) — как
сетка iOS; карточки без подписи и однострочные перестают прыгать между
собой при рефетче.
